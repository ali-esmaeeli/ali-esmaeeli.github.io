# aliesmaeeli — personal website

A single static page (`index.html`) plus `cv.pdf`. No build step.

## Host on GitHub Pages
1. Create a repo named `ali-esmaeeli.github.io` and upload `index.html` and `cv.pdf`.
2. Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/`.
3. Site goes live at `https://ali-esmaeeli.github.io`.

## Move to another server
Copy the two files to any web host's public folder. That's it.

## Custom domain (optional)
Add a file `CNAME` containing your domain (e.g. `aliesmaeeli.com`) and point the domain's DNS to GitHub Pages.
